# Architecture Decision Records (ADRs)

Ce dossier contient les décisions architecturales globales.

## Format ADR

```markdown
# ADR-XXX: Titre de la Décision

## Status
[Proposed | Accepted | Deprecated | Superseded by ADR-YYY]

## Context
Quel est le problème ? Pourquoi devons-nous prendre cette décision ?

## Decision
Quelle est la décision prise ?

## Consequences
- Avantages
- Inconvénients
- Risques
```
